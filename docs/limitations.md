# Limitations

1. The public repository contains a small number of implementation artifacts relative to the architecture described in the README.
2. Azure-service claims require screenshots/run evidence.
3. The exact schema of `order_items.csv` should be verified before finalising the physical warehouse model.
4. Pipeline performance depends on data volume, cluster configuration and cloud environment.
5. The dataset may not represent a production retail workload.
6. Sensitive source fields should not be exposed in analytics outputs.
