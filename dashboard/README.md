# Power BI Dashboard

Create a Power BI dashboard with these pages:

1. **Executive Overview**
   - Total orders
   - Active customers
   - Orders by month
   - Order-status mix

2. **Customer Analytics**
   - Orders per customer
   - Geographic distribution
   - Repeat customers

3. **Operations**
   - Order-status trends
   - Daily/monthly volume
   - Data-quality exceptions

4. **Product / Order Items**
   - Product-level metrics using the actual order-item schema

Add the `.pbix` file and screenshots after the dashboard is actually built.
